This policy describes how this browser extension handles information when you save authentication accounts, generate one-time codes, scan a page for setup QR codes, fill a code into a website, or use account and cloud features.

The extension's developer name is Modern 2FA verifier. Its ShipLang cloud sync, sign-in, membership and payment services are operated by weidali ltd.

Authentication secrets can be synchronized.

Authentication accounts are stored in browser sync storage. Separately, enabling ShipLang cloud sync sends authentication secrets and account details to ShipLang. Generating a code takes place in your browser; this does not mean that all account data stays only on your device.

1. Data we process

Authentication accounts

The extension processes the secret keys you enter, import, or obtain from setup QR codes, along with account names or labels, service names, authentication type, algorithm, number of digits, time period, and counter where applicable. Imported records may also contain icon information, setup URLs, and groups. This information is used to manage accounts and generate authentication codes.

Accounts and preferences, including site filtering and automatic filling, are saved in Chrome's extension sync storage. Chrome may synchronize this information to other signed-in browser installations according to your browser settings. This browser service is separate from ShipLang cloud sync.

Settings and local service state

The extension stores service sign-in and membership information, the cloud-sync password you choose to save, temporary sign-in state, and an icon cache in local extension storage. Membership information is used to display membership status and account-limit reminders.

2. Website access and authentication codes

When you open the extension, it reads the active tab's address to show accounts associated with that site. When you request a page scan, it reads image and canvas pixels on the page and decodes authentication setup QR codes in your browser.

Clicking a code copies it to your clipboard. With automatic filling enabled, the extension also places that code into an appropriate input on the active page and triggers the page's input events. That website can then receive the code. Automatic filling is enabled by default and can be disabled in settings.

The extension's diagnostic console messages can include generated codes and information about page input fields during filling. These messages are local browser diagnostics.

3. ShipLang cloud sync

Cloud sync connects to shiplang.com. After you sign in and save a cloud-sync password, synchronization sends your service account email, application identifier, sync password, language, and authentication account information to this service. Account information includes the actual authentication secret, service name, account label, authentication type, and algorithm.

A synchronization can upload existing accounts that are missing from the cloud and download accounts stored there. Once sign-in information and a sync password are saved, adding or editing accounts can also send changes to the service. Deleting an account can send a cloud deletion request.

These requests use HTTPS. The extension sends secrets and the sync password as request URL parameters; it does not encrypt them with a separate client-side encryption layer before sending them. The sync password is also stored in local extension storage. This policy does not describe this feature as end-to-end encryption.

4. Sign-in, membership and payment

Sign-in and membership payment open hosted pages at crx.shiplang.com. The extension passes its application and extension identifiers, version, interface language, and, when available, your account email and membership expiration time. Account and membership information returned by the service is saved locally.

Google provides sign-in authentication. The hosted service uses the sign-in result and your account email to provide your service account. The extension checks account counts and membership expiration locally to show upgrade reminders.

Payments use PayPro or Stripe through the hosted checkout. The payment provider handles the billing, transaction and payment information needed for checkout under its own privacy policy. weidali ltd maintains account, payment and membership records to administer the service.

5. Permissions

  • Storage: Saves authentication accounts, preferences, sign-in state, and the other local and synchronized information described above.
  • Tabs: Reads the active tab address for site matching and communicates with that page for scanning and filling.
  • Access to all websites: Allows the page script to support QR scanning and code filling on websites you use, and allows requests to the cloud service. You can manage permitted sites through Chrome's extension settings.

6. Recipients and third-party services

  • Google / Chrome: Provides Google sign-in and, separately, browser synchronization when enabled. See the Google Privacy Policy.
  • weidali ltd / ShipLang: Operates the hosted services and receives the sign-in, membership, payment and cloud data described in this policy.
  • PayPro and Stripe: Process checkout and payment information. See the PayPro Privacy Policy and Stripe Privacy Policy.
  • Websites you fill codes into: Receive the codes entered into their pages.
  • Support email: Messages you send to the contact address are processed to respond to your inquiry or deletion request, using the email services involved in delivery.
  • GitHub: Hosts this policy page and processes website requests under the GitHub Privacy Statement. The page itself contains no analytics scripts, forms, or external fonts.

7. Retention and deletion

Saved browser authentication accounts remain available until removed or cleared. Browser synchronization and its removal behavior also depend on your Chrome settings.

Deleting one account removes its browser sync record. If service sign-in information and a cloud password are available, the extension also sends a request to mark that cloud account as deleted. A successful local deletion does not confirm that the cloud record has been permanently erased.

Clear All Data clears the extension's browser sync storage, icon cache, and saved cloud-sync password. It does not send a request to delete all ShipLang cloud records, and it does not remove the locally stored service sign-in information. It also does not delete backup files you previously exported.

ShipLang service records: weidali ltd retains cloud authentication data, account records, payment records and service logs long term, until you request deletion. To request deletion, email e@ShipLang.com. Requests are processed within seven days of receipt. weidali ltd does not maintain backups of this service data.

This retention and deletion process applies to data held by weidali ltd. Google, PayPro, Stripe and GitHub manage data in their own services under their respective privacy policies. Deleting data from ShipLang does not itself delete records held independently by these providers.

8. Your choices

You can edit or delete saved accounts, turn off automatic filling and site filtering, manage Chrome synchronization and site access, or choose not to enable ShipLang cloud sync.

You can import supported account files and export accounts to a text backup. Exported files contain authentication secrets in readable authentication URLs and are not encrypted by the extension. Store or delete these files using your device's file controls, and share them only with recipients you intend to receive those secrets.
